# JavaScript

A collection of JavaScript code examples, practice exercises, and concept explorations created while learning JavaScript.

## About

This repository documents my journey of learning JavaScript through online tutorials and hands-on coding practice. It contains examples and exercises covering core language fundamentals as well as additional concepts explored along the way.

The code serves as a personal reference for revisiting JavaScript syntax, understanding language behavior, and strengthening programming fundamentals.

## Topics Covered

- **JavaScript Fundamentals** — variables, data types, operators, and expressions
- **Control Flow** — conditional statements and loops
- **Functions** — function declarations, expressions, and arrow functions
- **Arrays and Objects** — data manipulation and built-in methods
- **DOM Manipulation** — interacting with and modifying web page elements
- **Events** — handling user interactions and browser events
- **Modern JavaScript (ES6+)** — modern syntax and language features
- **Object-Oriented Programming** — objects, classes, and related concepts
- **Advanced JavaScript Concepts** — deeper exploration of language behavior and features
- **Asynchronous JavaScript** — callbacks, promises, and async/await
- **Practice Exercises** — small programs and examples for reinforcing concepts

*The list describes the general learning areas; individual topics may vary across the examples in the repository.*

## Getting Started

### Prerequisites

- A modern web browser with developer tools.
- A code editor such as Visual Studio Code.
- Node.js, if you want to execute standalone JavaScript files outside the browser.

### Clone the Repository

```bash
git clone https://github.com/naba93980/javascript.git
cd javascript
```

### Running the Code

For standalone JavaScript files supported by Node.js:

```bash
node filename.js
```

For examples that interact with HTML or the DOM, open the corresponding HTML file in a browser.

Some examples may require a specific HTML page or browser environment to run correctly.
